Google Sheet Sync

Every add, edit and delete is written to your Library tab

Not connected: changes are saved in this browser only.
1Secret token

A password that stops strangers reading or writing your sheet if they find the URL. Generated once and kept in this browser, never in the page's code.

2Install the script in your Sheet
  1. Click Copy Code.gs; your token is already inside.
  2. Open the Game Logger sheet → Extensions → Apps Script.
  3. Select everything in Code.gs, paste over it, press Ctrl+S.
3Deploy it as a Web app
  1. Deploy → New deployment → gear icon → Web app.
  2. Execute as: Me · Who has access: Anyone.
  3. Deploy → Authorize → pick your account → Advanced → Go to project (unsafe) → Allow. (It's your own script; Google warns on all unverified ones.)
  4. Copy the Web app URL (ends in /exec).
4Connect

Connecting replaces this browser's copy with what's in the Sheet. The Sheet is the master copy.

Add your phone / another PC

Copies a one-time link that connects another device instantly. It contains your token, so only send it to yourself (e.g. Saved Messages / notes).

Changed Code.gs later? Deploy → Manage deployments → ✎ Edit → Version: New version. The URL stays the same.
